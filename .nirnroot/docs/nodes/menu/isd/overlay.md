# menu: `overlay`

Build the elements with `document.createElement`, styled inline (a fixed,
centred panel over the canvas, `#160d13` behind light text, the buttons
stacked, one under the other, in the table's order). Open and close by
`style.display` (`block` / `none`).

This Node's edge:

- [eed:menu](../EED.md)

# API Shapes:
None

# Inbound Side-Effects:
Clicks on its buttons.

# Outbound Side-Effects:
Its elements in the page, shown and hidden.
